Glossário de HTML

<p>
Cria um parágrafo. Exemplo: <p>Olá</p>
<h1>
Título principal. Exemplo: <h1>Início</h1>
<a>
Cria uma ligação. Exemplo: <a href="a.html">A</a>
<img>
Insere uma imagem. Exemplo: <img src="f.jpg">
<ul>
Lista não ordenada. Exemplo: <ul><li>A</li></ul>
<ol>
Lista ordenada. Exemplo: <ol><li>A</li></ol>
<strong>
Texto importante. Exemplo: <strong>Atenção</strong>
<mark>
Texto destacado. Exemplo: <mark>HTML</mark>
